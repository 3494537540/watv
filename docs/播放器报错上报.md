# 播放器报错上报（对接苹果 CMS）

## 功能

App 播放页可将当前播放失败信息提交到 CMS **留言本**，后台路径与模板 `MAC.Gbook.Report` 一致。

## 入口

1. 播放失败态：「重试」旁的 **报错**
2. 播放设置侧栏：**报错** 瓦片（卡顿/错源也可手动报）

## 接口

- `POST {macCmsBase}/index.php/gbook/saveData`
- 表单字段：
  - `gbook_rid`：影片 `vod_id`
  - `gbook_content`：报错正文（含片名、线路、选集、播放地址、错误信息）
  - `verify`：站点开启留言验证码时必填

实现：`MacCmsApi.reportPlayError`（`lib/services/maccms_api.dart`）  
弹窗：`lib/widgets/player/play_error_report.dart`

## 后台查看

CMS 管理后台 → **留言本**（报错类留言）。

## 注意

- 需站点开启留言/报错功能；若强制登录或验证码，按提示处理。
- 会尽量带上已登录会员 Cookie（`CmsAuthController`）。
