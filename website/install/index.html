请用 iPhone / iPad 的 Safari 打开本页。微信/QQ 内置浏览器通常无法安装描述文件和 App。

安装步骤
1. 用 Safari 打开本页，点「下载描述文件」并按提示安装
2. 设置 → 通用 → VPN与设备管理 / 描述文件，确认已安装
3. 回到本页点「安装哇TV」（证书签名安装）
4. 回到桌面等待图标出现；若提示未信任，再到设备管理中信任企业级应用
5. 打开 哇TV
